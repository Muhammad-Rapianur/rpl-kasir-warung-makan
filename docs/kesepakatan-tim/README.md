# Dokumentasi Kesepakatan Tim (Team Agreements)
## Sistem Kasir Warung Makan (KasirWarung)

Folder ini berisi pedoman kesepakatan tata kelola, aturan kolaborasi kelompok, etika kerja, dan pembagian peran dalam pengerjaan proyek tugas mata kuliah **Rekayasa Perangkat Lunak (RPL)**.

---

## 📋 Berkas dalam Folder Ini
- **[`kesepakatan-tim.md`](kesepakatan-tim.md)** : Piagam kesepakatan kerja tim (*Team Working Agreement*) lengkap yang mencakup:
  1. **Pembagian Peran & Tanggung Jawab:** Struktur peran tim dan matriks RACI (*Responsible, Accountable, Consulted, Informed*).
  2. **Saluran & Ritme Komunikasi:** Saluran resmi (WhatsApp, GitHub PR/Issues, Lab), SLA respon pesan $\le 4\text{ jam}$, dan jadwal *standup meeting*.
  3. **Kesepakatan Alur Kerja Git & Review:** Perlindungan branch `main`, penamaan branch, batas waktu tinjauan PR $\le 24\text{ jam}$, dan konvensi *Conventional Commits*.
  4. **Etika Penggunaan AI & Vibe Coding:** Prinsip *Human-in-the-Loop*, transparansi pencatatan log AI, dan perlindungan privasi data klien UMKM.
  5. **Standar Kualitas Kerja (*Definition of Done - DoD*).**
  6. **Resolusi Hambatan & Manajemen Konflik.**
  7. **Pernyataan Komitmen Bersama.**
