# Dokumentasi Backlog Proyek (KasirWarung)

Folder ini berisi dokumen perencanaan kerja, pembagian tugas, dan pelacakan progres menggunakan pendekatan *Agile / Scrum* untuk proyek **Sistem Kasir Warung Makan (*KasirWarung*)**.

---

## 📋 Berkas dalam Folder Ini
- **[`product-backlog.md`](product-backlog.md)** : Dokumen utama Product Backlog yang mencakup:
  1. **Konsep & Tata Kelola Backlog:** Aturan turunan kebutuhan dari SRS dan kriteria beban tugas maksimal 1 hari kerja per tugas.
  2. **Peta Jalan Sprint (*Sprint Roadmap*):** Pembagian 4 siklus Sprint (Sprint 1: Kasir Inti MVP, Sprint 2: QRIS & Manajemen Menu, Sprint 3: Cetak Struk & Rekap Omzet, Sprint 4: Pengujian & Validasi Klien).
  3. **Tabel Product Backlog Terprioritas:** Pemetaan 15 butir backlog terhadap Kebutuhan Fungsional (KF), prioritas MoSCoW, estimasi *Story Points*, dan alokasi Sprint.
  4. **Rincian Tugas Sprint 1 (*Sprint Backlog Breakdown*):** 8 tugas teknis terinci untuk Sprint pertama (T-1.1 s.d. T-1.8).
  5. **Definition of Done (DoD):** Tolok ukur penyelesaian butir kerja sebelum di-merge ke `main`.

---

## 🔄 Hubungan dengan Dokumen Lain
- **[SRS Ringkas](../srs/srs.md):** Sumber utama asal-usul setiap butir backlog (kolom ID Kebutuhan KF).
- **[PRD](../../PRD.md):** Sumber kriteria penerimaan fungsional (*Given–When–Then*) untuk menguji keberhasilan setiap butir backlog.
- **[Aturan Proyek](../../aturan-proyek.md):** Panduan branching Git dan konvensi commit saat menyelesaikan tugas backlog.
